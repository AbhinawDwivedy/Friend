# 📸 HER PHOTOS GUIDE

Place her photos directly into this folder (`public/images/`):

1. Scratch Card Reveal Photo:
   - Add her photo here (e.g. `maya-photo.jpg`).
   - In `src/config/content.js`, set `revealedImage: "/images/maya-photo.jpg"`.

2. Memory Gallery Photos:
   - Add photos here (e.g. `pic1.jpg`, `pic2.jpg`, etc.).
   - In `src/config/content.js`, update the paths in `gallery.photos`:
     `src: "/images/pic1.jpg"`
     `caption: "Your custom caption here"`

Beautiful aesthetic vector illustrations are currently loaded as defaults so the site works and looks gorgeous right away!
