# 🎵 HER AUDIO RECORDING

To add her singing recording:
1. Copy her audio file into this folder (e.g., `song.mp3` or `voice.m4a`).
2. Open `src/config/content.js`.
3. Set `audioSrc: "/audio/song.mp3"` (replace with your file's name).

Note: If no audio file is provided yet, clicking "Play Song" on the website automatically plays a soothing music-box chime, so everything works out of the box!
